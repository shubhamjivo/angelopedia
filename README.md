# Angelopedia

Next.js App Router implementation of the Angelopedia website, converted from the Figma file `angelopedia-website-new-design`.

## Stack

- Next.js 16 (App Router, Server Components by default)
- TypeScript
- Tailwind CSS 4 with design tokens in `app/globals.css`
- Swiper for the Latest News carousels

## Develop

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).
